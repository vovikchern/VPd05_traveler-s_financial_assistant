# 💰 Финансовый помощник путешественника

Telegram-бот для планирования бюджета поездки: создаёт «путешествие» с валютной парой, берёт актуальный курс через API exchangerate.host, записывает расходы и всегда показывает остаток сразу в двух валютах — в валюте страны пребывания и в вашей домашней.

---

## ✨ Возможности

### Путешествия
- **Создание путешествия** в три шага: страна выезда → страна назначения → стартовая сумма. Бот сам определяет валюты по названиям стран (работают и русские названия: «Россия», «Китай», «Италия»…).
- **Валютная пара и курс** берутся из API exchangerate.host: например, `Россия → Китай (RUB → CNY)`.
- **Несколько поездок одновременно** — можно переключаться между путешествиями; активное помечается ✅ и используется во всех расчётах.

### Расходы с категориями и примечаниями
- Чтобы записать трату, достаточно **прислать боту число** — оно считается расходом в валюте страны пребывания.
- Бот конвертирует сумму в домашнюю валюту (через API, а при сбое — по курсу путешествия) и просит **выбрать категорию**: 🍔 Еда, 🚕 Транспорт, 🏨 Жильё, 🎉 Развлечения, 📦 Прочее.
- После выбора категории можно добавить **произвольное примечание** — рукописный текст до 100 символов: «ужин в ресторане», «покупка фруктов на рынке». Примечание необязательно — есть кнопка «⏭ Без примечания».
- Примечания видны в истории, поэтому спустя недели легко понять, на что именно был потрачен каждый расход.

### История расходов
- История группируется **по категориям** с итогами: сколько потрачено в каждой статье — в обеих валютах и сколько покупок.
- Каждая статья раскрывается (drill-down): список покупок с суммами, датами и примечаниями 📝, плюс возврат «⬅ Назад к статьям».

### Баланс
- Остаток всегда показывается **в двух валютах**: `Остаток: 11 953.1 CNY = 148 202.19 RUB`.
- Рядом — потрачено и курс, по которому считается пересчёт.
- Бот не даст записать расход больше остатка — предупредит и подскажет проверить число или изменить курс.

### Ручной курс
- `/setrate` позволяет временно задать свой курс (например, «как в обменнике») — все пересчёты и остатки мгновенно пересчитываются.
- Если API недоступен при создании путешествия, бот сам предложит ввести курс вручную.

### Остаток запросов API
- В каждом балансе виден остаток месячной квоты API: `⚡ Осталось запросов API в октябре 2026: 74 из 100`.
- Месяц подставляется автоматически, счётчик уменьшается по мере использования — легко контролировать, не выйдешь ли за бесплатный лимит.
- Чтобы лимит не расходовался зря, ответы API **кешируются на 10 минут**.

### Меню
- Все действия собраны в **нижней клавиатуре Telegram**, которая всегда под рукой: 🗺 Новое путешествие, 🧳 Мои путешествия, 💰 Баланс, 📜 История расходов, ⚙ Изменить курс.
- Бот следит, чтобы меню было раскрыто после каждого своего ответа.

## 🤖 Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и стартовое меню |
| `/newtrip` | Создать новое путешествие |
| `/switch` | Выбрать активное путешествие |
| `/balance` | Баланс активного путешествия |
| `/history` | История расходов (с drill-down по категориям) |
| `/setrate` | Задать свой курс обмена |

Число в чате = расход в валюте страны пребывания.

## 🗂 Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот: команды, меню, машина состояний диалогов |
| `current_api.py` | Работа с API exchangerate.host: курсы, конвертация, кеш, учёт квоты |
| `database.py` | Слой данных на SQLite: пользователи, путешествия, расходы |
| `countries.py` | Сопоставление «страна → валюта» |
| `currency_travel_bot.db` | База данных SQLite (создаётся автоматически) |

Хранение данных: SQLite, при первом запуске база и таблицы создаются автоматически; старые базы мигрируют без потери данных (добавление категорий и примечаний).

## 🚀 Запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/vovikchern/currency-travel-bot.git
cd VPd05_traveler-s_financial_assistant
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # Windows (PowerShell)
source .venv/bin/activate           # Linux / macOS
pip install -r requirements.txt
```

### 3. Прописать ключи

Создайте файл `.env` рядом с `bot.py`:

```
TELEGRAM_BOT_TOKEN=токен_вашего_бота_от_BotFather
CURRENCY_API_KEY=ключ_exchangerate.host
```

- `TELEGRAM_BOT_TOKEN` — получите у [@BotFather](https://t.me/BotFather) командой `/newbot`.
- `CURRENCY_API_KEY` — получите на [exchangerate.host](https://exchangerate.host/) (есть бесплатный тариф: 100 запросов в месяц — боту этого достаточно благодаря кешированию).

### 4. Запустить

```bash
python bot.py
```

Бот работает через long polling — внешний веб-хук не нужен.

## ⚙️ Как это работает внутри

- **Машина состояний** (`user_states`) ведёт пошаговые диалоги: создание путешествия (страна → страна → сумма), смена курса, запись расхода (сумма → категория → примечание). Апдейты Telegram обрабатываются последовательно (`threaded=False`), поэтому быстрые сообщения пользователя не «перепрыгивают» шаги диалога.
- **Кеш API** (10 минут) экономит месячную квоту бесплатного тарифа; остаток квоты бот читает из заголовков ответа API и показывает пользователю.
- **Отказоустойчивость**: при недоступности API бот предлагает ручной ввод курса, а конвертацию расхода считает по сохранённому курсу путешествия.
